# Unit 1 Tasks and Assignments

This directory contains practical and theoretical assignments for students to reinforce their understanding of Artificial Intelligence Foundations and Large Language Models (LLMs).

## Task List

1. [Task 1: Simple LLM API Call (Python)](./task-1-simple-llm-call.md)
   - *Hands-on coding exercise to make a programmatic API call to an LLM.*
2. [Task 2: "Prompt and Evaluate" (Hands-On LLM Interaction)](./task-2-prompt-and-evaluate.md)
   - *Interacting with AI chat interfaces and evaluating outputs.*
3. [Task 3: AI Application Scavenger Hunt (Real-World Mapping)](./task-3-ai-application-scavenger-hunt.md)
   - *Identifying AI domains (NLP, CV, Speech) in everyday apps.*
4. [Task 4: Visualizing the Transformer (Conceptual Diagramming)](./task-4-visualizing-transformer.md)
   - *Drawing the Transformer architecture and explaining Self-Attention.*
5. [Task 5: The Generative AI Timeline](./task-5-generative-ai-timeline.md)
   - *Researching specific generative models like GANs or Diffusion.*
6. [Task 6: AI Ethics & Limitations Debate Prep](./task-6-ai-ethics-debate.md)
   - *Analyzing real-world AI failures, biases, and hallucinations.*
