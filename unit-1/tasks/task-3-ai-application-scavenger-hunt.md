# Task 3: AI Application Scavenger Hunt (Real-World Mapping)

**Objective:** Connect theoretical AI domains to everyday applications you use.

**Instructions for Students:**
1. Look at your smartphone, daily software tools, or websites you frequently visit.
2. Identify at least one specific feature or app that uses:
   - **Natural Language Processing (NLP)** (e.g., text prediction)
   - **Computer Vision (CV)** (e.g., facial recognition)
   - **Speech AI** (e.g., voice-to-text)
   - **A Generative Model** (if applicable)

**Deliverable:** 
Create a 1-page document listing the tool/feature you found. For each one:
- State which AI domain it belongs to.
- Give a brief guess as to whether the underlying model is **Generative** (creating new data) or **Discriminative** (classifying/predicting). Explain your reasoning.
