# Task 2: "Prompt and Evaluate" (Hands-On LLM Interaction)

**Objective:** Understand how LLMs work in practice and identify their strengths and limitations from an end-user perspective.

**Instructions for Students:**
1. Choose two different free LLM chat interfaces (e.g., ChatGPT-3.5/4o-mini, Google Gemini, Claude, or Meta Llama via HuggingFace).
2. Write a prompt asking the model to explain a complex topic (e.g., "Explain quantum computing to a 10-year-old").
3. Write a second prompt asking it to solve a tricky logic puzzle (e.g., "A man has a wolf, a goat, and a cabbage...").
4. Compare the outputs from both models. 

**Deliverable:** 
Write a short report (300-500 words) evaluating the responses. 
- Did any model "hallucinate"? 
- How would you rate them using human evaluation metrics (Fluency, Relevance, Coherence, Helpfulness)?
