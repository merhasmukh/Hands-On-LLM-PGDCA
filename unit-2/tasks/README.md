# Unit 2 Tasks and Assignments

This directory contains practical programming assignments for students to reinforce their understanding of Advanced API Usage and Performance Optimisation.

## Task List

1. [Task 1: Parameter Tuning Experiments](./task-1-parameter-tuning.md)
   - *Experimenting with Temperature and Top-p to control output randomness.*
2. [Task 2: Streaming Responses & TTFT](./task-2-streaming-responses.md)
   - *Implementing streaming API calls and measuring Time-To-First-Token.*
3. [Task 3: Asynchronous API Calls](./task-3-async-api-calls.md)
   - *Using `asyncio` to execute multiple LLM requests concurrently.*
4. [Task 4: Rate-Limit Handling & Batch Processing](./task-4-rate-limits-and-batching.md)
   - *Implementing exponential backoff to handle `429 Too Many Requests` errors.*
5. [Task 5: Capstone Mini-Project — Smart Client](./task-5-smart-client-project.md)
   - *Building a tool that extracts structured JSON data from text while tracking token usage and calculating API costs.*
