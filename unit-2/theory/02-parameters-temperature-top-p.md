# 2.2 Parameters: Temperature, Top-p, Stop Sequences, Max Tokens

When making an API call to an LLM, you can tune several parameters to control the behavior, creativity, and length of the generated output.

## 1. Temperature

**Temperature** controls the randomness or "creativity" of the model's responses.

* **Range:** Typically between 0.0 and 2.0 (though most use cases stay between 0.0 and 1.0).
* **Low Temperature (0.0 - 0.3):** The model becomes highly deterministic, focused, and predictable. It almost always chooses the most likely next word. **Best for:** Coding, math, data extraction, and factual Q&A.
* **High Temperature (0.7 - 1.0+):** The model becomes more random and creative, picking less likely words. **Best for:** Brainstorming, creative writing, and generating varied responses.

## 2. Top-p (Nucleus Sampling)

**Top-p** is an alternative to temperature for controlling randomness. 

* Instead of adjusting the probabilities of all words, Top-p considers only the tokens comprising the top *p* probability mass. 
* For example, a `top_p` of 0.1 means only the tokens comprising the top 10% probability mass are considered.
* **Best Practice:** Generally, you should alter *either* Temperature *or* Top-p, but not both at the same time.

## 3. Max Tokens

**Max Tokens** sets a hard limit on the length of the generated output.

* It helps control costs and prevents the model from generating infinitely long responses.
* Keep in mind that setting `max_tokens` too low might cause the model to cut off mid-sentence.
* Note: This only limits the *output* length. The total context window (input + output) is determined by the specific model you choose.

## 4. Stop Sequences

A **Stop Sequence** is a predefined string (or list of strings) that, if generated by the model, will cause the generation to halt immediately.

* **Example Use Case:** If you are using a model to generate a Python function, you might set the stop sequence to `\ndef` so the model stops before it starts writing an entirely new function.
* The stop sequence itself is not included in the final output.
